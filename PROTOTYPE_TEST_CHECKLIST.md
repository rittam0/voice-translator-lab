# Owner listening checklist

For each English/Hindi/Odia → Japanese/French route:

- [ ] Source transcript is correct (exact English; usable Hindi/Odia).
- [ ] English reference preserves source meaning.
- [ ] Target text preserves every sentence and the first sentence is present.
- [ ] Target pronunciation and meaning are acceptable.
- [ ] Final WAV contains every sentence in order with natural gaps.
- [ ] Voice resemblance is acceptable without claiming exact identity.
- [ ] No severe speed, truncation, noise, or distortion.
- [ ] Displayed latency/resource values came from this run.

Odia only:

- [ ] Direct Seamless baseline reviewed.
- [ ] Odia V2 transcript and English translation reviewed.
- [ ] Qwen speaker-only and transcript-conditioned outputs compared.
- [ ] OmniVoice reviewed or exact skip reason recorded.
- [ ] Five manifest recordings completed.

Browser:

- [ ] English/Hindi/Odia and Japanese/French selectors work.
- [ ] Odia is marked Experimental.
- [ ] Permission, empty, timeout, stage, and backend errors are truthful.
- [ ] Waveform is live while recording and frozen while processing.
- [ ] Text/reference/latency appear only after success.
- [ ] Autoplay or visible fallback works.
- [ ] Second recording cleans up the old audio URL.
